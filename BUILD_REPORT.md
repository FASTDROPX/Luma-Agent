## Проверка установленного приложения

Подписанный release APK установлен в отдельный read-only экземпляр эмулятора Android 15 / API 35; приложение запускается без сбоя AndroidRuntime.

Проверены экран доступа, раскрытие необязательных доступов и реальная цепочка Activity Result для READ_CONTACTS. Временный локальный тестовый OpenAI-совместимый провайдер выдал `find_contacts`; приложение показало карточку. После нажатия «Don’t allow» карточка осталась открытой. После повторного запроса и «Allow» инструмент выполнился, карточка закрылась и ответ модели продолжился. Доступ к экрану не выдавался, курсор не запускался. Эта проверка использовала сценарный локальный ответ, а не платную модель.

Звонки, отправка SMS, установка стороннего APK, удаление личных данных и работа реальных аппаратных датчиков на физическом телефоне не выполнялись. Их доступность зависит от Android и оборудования; ограничения описаны в `docs/ACCESS_TOOLS.md`.
