# Доступы и инструменты Luma 0.9.0

Настройки не выдают разрешения автоматически. Доступ проверяется перед конкретным действием; в чате появляется карточка с назначением доступа и кнопкой системного запроса. После выдачи текущий шаг продолжается без повторного запроса модели. Отказ оставляет карточку открытой. «Пропустить» возвращает модели факт невыполненного действия. Остановка задачи отменяет ожидание.

«Продолжить без доступа» существует только для реализованного альтернативного пути. Он использует публичный интерфейс Android и уже выданные разрешения. Чтение личных данных без разрешения не предлагается.

## Подтверждения и результаты

Звонок, отправка SMS, съёмка/запись, изменение контактов и календаря, удаление файлов/медиа, установка APK и показ заметки поверх приложений требуют подтверждения Luma в режиме запросов. В полном доступе эти подтверждения отключены после отдельного согласия при включении режима. Даже при выдаче всех разрешений Android может показать собственное окно.

Системная съёмка, установка, видимость Bluetooth и удаление медиа передаются из задачи в Activity Result API через карточку «Продолжить» в режиме запросов; в полном доступе системное действие открывается автоматически, когда Android разрешает переход. Ответы связаны с уникальным id текущего действия; устаревший ответ не завершает новое действие. Отмена съёмки/удаления не считается успехом. Установщик не гарантирует подтверждение результата, поэтому инструмент возвращает `verified=false`. Для звонка, отправки SMS и уведомлений приложение тоже не выдаёт передачу запроса системе за проверенное завершение.

При отказе без возможности повторного запроса открываются настройки приложения. Фоновая геолокация запрашивается после обычной, на Android 11+ пользователь выбирает её в настройках. Ключ подписи и пароль не требуются установленному приложению и не входят в исходники.

## Практические ограничения Android

- Фото/видео снимаются в видимом интерфейсе приложения камеры. Результат хранится в приватной папке `files/captures` Luma и возвращается как URI FileProvider; `open_capture` открывает этот файл в просмотрщике. Микрофон записывает до 30 секунд, пока Luma видима. Скрытая запись не запускается.
- `get_background_location` делает один запрос координат; постоянной слежки или отдельного сервиса отслеживания нет. Фоновая выдача координат зависит от ограничений ОС.
- `wait_sms` ждёт до 30 секунд и слушает только защищённое системное событие. Слушатель удаляется при завершении/остановке. Архив сообщений читается отдельным `read_sms`.
- `read_notifications` читает только текущие активные уведомления. Постоянный архив не создаётся.
- Датчик шагов возвращает накопленное значение с перезагрузки; это не счётчик за сегодня. Пульс доступен только при наличии соответствующего датчика. Ожидание одного замера ограничено десятью секундами.
- `scan_bluetooth` ищет BLE-устройства пять секунд. Устаревший Bluetooth classic и универсальное управление произвольными устройствами не реализуются этим инструментом.
- `wifi_scan` использует последние результаты системного сканирования и требует точного местоположения даже на новых версиях Android. `wifi_connect` использует WifiNetworkSpecifier с системным подтверждением; соединение локальное и действует до конца задачи. Это не постоянное сохранение Wi-Fi сети в системных настройках.
- Все файловые пути канонизируются и ограничены общей памятью. Доступ к приватным данным других приложений не предоставляется. Удаление каталогов допускается только для пустых папок. Текст — до 64 КБ, APK — до 256 МБ.
- Список медиа возвращает id и URI, а список календаря — id событий/календарей для последующего адресного действия.
- Полноэкранный показ решает Android: выдача доступа сама по себе не гарантирует открытие поверх текущего экрана. Экономия батареи и ограничения производителя могут приостанавливать фоновую работу.
- Роли приложения по умолчанию, VPN, клавиатура, администратор устройства и привилегии системного приложения не входят в эти 30 доступов. Приложение не объявляет их реализованными возможностями.

## Поиск и размышления

Кнопка «Поиск» доступна и в агентском чате. Инструменты `web_search` / `read_page` используют выбранный поисковик Luma (DuckDuckGo, Tavily, Brave или SearXNG). На задачу — до четырёх поисков и пяти чтений страниц. Данные возвращаются как недоверенное содержимое, ссылки следует цитировать в ответе. При выключенном поиске обработчик отклоняет вызов и предлагает включить его.

Телефонные, новые и поисковые инструменты присутствуют и в native schemas, и в JSON-каталоге. «Размышления» проверяют отсутствие изменений/ошибки и запрещают повтор того же действия на том же экране. Для задач открытия ссылки дополнительно распознаётся характерное меню сообщения вместо перехода. Это эвристика, а не гарантия понимания результата любого интерфейса; максимум — шесть разборов за задачу.

Текстовый ответ не включает курсор. Курсор появляется перед разрешённым экранным действием, скрывается при запросе доступа и системном окне. Служба выполнения задачи остаётся foreground service с системным уведомлением: это необходимо для фоновой работы и отличается от экранного курсора.
