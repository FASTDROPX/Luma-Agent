# GGUF внутри Luma

Тестовая версия 1.0.0-test2 запускает текстовые GGUF непосредственно на Android. Сервер, PocketPal и API-ключ для этого не нужны. Файл PocketPal, предоставленный для сравнения, определился как com.pocketpalai 1.20.1; код или бинарные библиотеки из него не копировались.

## Запуск

1. **Модели → Каталог**: найдите GGUF на Hugging Face и скачайте. В завершённой загрузке нажмите **Использовать в Luma**.
2. Либо **Модели → На телефоне → Импортировать GGUF**: выберите файл системным проводником. Импорт создаёт закрытую копию; исходный файл остаётся вашим.
3. Откройте **Чат** и отправьте сообщение. Первый ответ включает загрузку весов в память. Загруженная модель остаётся доступной до явной выгрузки или завершения процесса Android.
4. **Выгрузить из памяти** освобождает веса. Удаление импортированной модели удаляет только копию Luma. Модели Hugging Face удаляются в списке загрузок.

Один и тот же локальный провайдер используется чатом, агентом, поиском и голосом. Голос преобразуется в текст и обратно отдельно. Поиск требует интернета, сам локальный вывод — нет. Для действий агента выбирайте instruct-модель, понимающую JSON-команды; способность выполнять сложные поручения определяется моделью. Телефонные разрешения и системные окна Android сохраняются.

## Поддержка и ограничения

- Встроен **llama.cpp**, закреплённый commit `6b9ba4f2e8c1436511956f0b3c309e2c9e642071`, лицензия MIT. Исходники подключены Git submodule; при клонировании используйте `git clone --recurse-submodules` или `git submodule update --init --recursive`.
- Поддерживаются **arm64-v8a и x86_64**, Android 8+. Вычисления идут на **CPU**; ускорение GPU/NPU в этой версии не реализовано.
- Поддерживаются одиночные текстовые GGUF с совместимой архитектурой и шаблоном диалога, например instruct-модели семейств Llama, Qwen, Gemma, SmolLM. Это не обещание совместимости с любым файлом GGUF.
- Разделённые GGUF, mmproj, vision, embedding/reranker и encoder/decoder-модели не поддерживаются. Текстовые файлы можно приложить к запросу; изображения требуют подходящего API-провайдера.
- Начните с модели 0,1–1,5B в Q4. Размер файла не равен полной потребности в RAM: дополнительно нужны контекст и рабочие буферы. Перед загрузкой Luma проверяет доступную память; Android всё равно может завершить процесс при нехватке ресурсов.
- Контекст выбирается во вкладке **На телефоне**: 2K/4K/8K/16K, с ограничением обучающего контекста GGUF. Старые обмены могут удаляться из контекста целиком; политика и последний запрос не обрезаются. Если они не помещаются, приложение предложит увеличить контекст или сократить запрос.
- «Авто» локального ответа — до 1024 новых токенов в оставшемся контексте. Явный лимит настраивается в параметрах модели. Достигнутый лимит сохраняет полученный текст. Скорость измеряется настоящими токенами движка; её нельзя переносить с эмулятора на телефон.
- Одновременно выполняется один локальный запрос. Кнопка остановки отменяет вычисление, а настройки памяти не меняются во время задачи.
- Лицензия скачиваемой модели независима от лицензии движка. Проверяйте карточку автора перед загрузкой.

## Сборка

Нужны Android NDK `28.2.13676358` и CMake `3.31.6`. Gradle собирает JNI-обвязку и статические библиотеки llama.cpp из закреплённого submodule; APK не скачивает исполняемый код во время работы. Даже debug-вывод собирается с оптимизацией `-O2`. Проверка Android ABI и ZIP-выравнивания 16 КБ выполняется при упаковке.

## Голосовой модуль

Загрузка русской Vosk использует основной источник на Hugging Face, оригинальный сервер и резервное зеркало GitHub. Каждый источник проверяется по одному SHA-256. Частичная загрузка сохраняется и возобновляется HTTP Range; если источник игнорирует Range, файл перезаписывается с начала. Ошибки DNS/TLS/таймаута/HTTP показываются отдельно.

При блокировке источников скачайте `vosk-model-small-ru-0.22.zip` через браузер и выберите **Настройки → Голос → Установить модель из ZIP**. Произвольные ZIP и другие модели не принимаются: требуется точная контрольная сумма русской модели. Нужно около 180 МБ свободного внутреннего места для архива и распаковки.
