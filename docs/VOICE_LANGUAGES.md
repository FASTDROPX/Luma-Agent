# Разговор и языки — 1.0.0-test4

## Как открыть

Подключите текстовую модель (API, сервер ПК или локальный GGUF). В **Настройки → Голос** выберите язык распознавания и нажмите **Скачать язык**. Для озвучки выберите **Luma**, язык и **Женский / Мужской**, затем **Скачать голос**. Прослушать пример можно отдельной кнопкой.

Откройте **Параметры чата → Голосовой разговор**. Появится отдельный экран со сферой Luma. Фразы автоматически отправляются после паузы, ответ озвучивается, затем снова включается прослушивание. Во время озвучки микрофон не записывает голос синтезатора.

- Частицы собираются к сфере при прослушивании и расходятся при ответе. Свет и размер сферы реагируют на уровень звука.
- Обводка расположена внутри окна Luma. Она плавно появляется при ответе, реагирует на озвучку и затухает после него. Оверлей управления другими приложениями не изменён.
- Микрофон внизу выключает запись до повторного нажатия. Стрелка сверху сворачивает экран; открыть его снова можно из голосовой карточки в чате. Крестик завершает разговор и его текущую задачу.
- **Чат / Агент** задаёт режим следующей фразы. Чат отвечает словами, агент может вызывать инструменты. Если требуется доступ или подтверждение, кнопка переведёт в чат к соответствующей карточке. Голос не отменяет разрешения Android и не снимает блокировку телефона.
- Настройки в правом верхнем углу позволяют выбрать голос и язык следующего ответа. Язык распознавания меняется после завершения разговора.
- «Меньше анимаций» сохраняет неподвижную сцену. Анимация приостанавливается, когда окно не видно.

## Голоса

| Язык | Женский | Мужской | Размер загрузки каждого |
|---|---|---|---|
| Русский | Ирина | Денис | около 21 МБ |
| English | Amy | Ryan | около 21 МБ |
| 中文 | Xiao Ya | Chaowen | около 14 МБ |
| Deutsch | Eva | Thorsten | 13 / 21 МБ |
| Français | Siwis | Tom | около 21 МБ |

Голоса Piper запускаются на CPU через sherpa-onnx. Пакеты скачиваются отдельно, проверяются по закреплённому SHA-256 и после установки не требуют интернета. Для распаковки требуется 300 МБ свободного места; установленный пакет занимает больше своего архива. Загрузка отменяется и продолжается с сохранённого места. Название голоса и его выбор пола определены конкретным пакетом, а не изменением высоты одного голоса.

Android TTS и совместимый речевой API сохранены как альтернативы. Пол и набор установленных голосов Android определяет системный движок; для гарантированного выбора пары используйте **Luma**. Для API переключатель выбирает coral / onyx; сервер должен поддерживать выбранные имена. Можно ввести своё имя голоса. Речевой API не зависит от текстовой модели.

Язык голосового ответа передаётся выбранной текстовой модели отдельной системной инструкцией. Качество языка и выполнение инструментов зависят от модели. Озвучка сообщения по кнопке читает существующий текст, не переводя его автоматически.

Для русского используется GigaAM v2 int8, для китайского — SenseVoice int8, для английского, немецкого и французского — общий Whisper Small int8. Старый Vosk заменён полностью. Вызов «Люма» обрабатывается локально через Silero VAD и выбранную модель распознавания. Фразы вызова можно изменить в настройках. Точность при шуме и особенности микрофона нужно проверить на телефоне.

## Интерфейс

**Настройки → Оформление → Язык интерфейса**: русский, English, 中文, Deutsch, Français или язык системы. Изменение применяется внутри приложения без потери истории. Языки интерфейса, распознавания и озвучки независимы. Системные окна Android используют настройки самого Android.

Переводы упакованы в APK (`assets/i18n`), при работе приложения сеть для перевода не используется. Каталоги подготовлены машинно с ручной проверкой основных элементов. Пользовательские сообщения, ответы модели, названия файлов и API-идентификаторы не переводятся интерфейсным слоем. Проверка `python tools/check_i18n.py` контролирует наличие строк и сохранение аргументов форматирования.

## Источники и лицензии

- [sherpa-onnx 1.12.20](https://github.com/k2-fsa/sherpa-onnx/tree/v1.12.20) и официальный Android AAR; JNI-классы и callback сохранены при R8. Удалены неиспользуемые C/C++ API-обёртки. ONNX Runtime и JNI-библиотеки совместимы с 16-КБ страницами памяти.
- [Официальные пакеты TTS](https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models). Пакеты включают свои `MODEL_CARD`; копии для выбранных голосов находятся в [voice-model-cards](voice-model-cards). Лицензии данных различаются; у части исходных карточек, включая Irina, лицензия датасета указана как Unknown. Голосовые веса не включены в APK.
- [GigaAM и Whisper: ревизии, хеши и лицензии](ASR_MODELS.md). Веса не входят в APK.
- Компоненты eSpeak NG в цепочке Piper имеют собственную лицензию GPL-3.0; [исходники eSpeak NG](https://github.com/espeak-ng/espeak-ng). Тексты лицензий движков упакованы в `assets/licenses`.

Нативные проверки находятся в `SpeechDeviceTest`: открытие пяти Vosk-моделей, генерация десятью голосами, воспроизведение с реальным уровнем звука и жизненный цикл разговорного экрана. Для этих проверок заранее установите соответствующие проверенные пакеты на тестовый эмулятор; в обычные JVM-тесты загрузки не входят.
