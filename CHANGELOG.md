# Changelog

## 0.5.2 — 2026-10-22

### Безопасность агента
- Убран встроенный список «опасных» слов в режиме «Полный доступ»: слова вроде
  «удалить» или «подтвердить» могли означать безобидное действие.
- Новая настройка «Запрещённые слова» («Настройки» → «Параметры модели»). Если слово
  есть в подписи нажимаемого элемента или во вводимом тексте, шаг ждёт подтверждения
  даже в полном доступе. Окно подтверждения называет совпавшее слово. Список общий
  для всех моделей, по умолчанию пуст.
- Нажатие по координатам (`tap_point`) больше не обходит проверку: подпись берётся
  у элемента под точкой и видна в окне подтверждения.

### Конфиденциальность
- Картинки из ответов модели больше не загружаются автоматически. Вместо них
  показывается ссылка «🖼 подпись», которая открывается в браузере только по нажатию.
  Так ответ не может незаметно отправить данные на чужой сервер через адрес картинки.
  Модуль Markwon image удалён из сборки.
- Обычный HTTP разрешён только для локальной сети и теперь проверяется прямо
  в HTTP-клиенте, а не только при сохранении адреса. Локальными также считаются
  169.254.0.0/16 и приватные/link-local IPv6 (fc00::/7, fe80::/10).

### Исправления
- Зависший жест (Android не подтвердил его за 5 с) — теперь ошибка одного шага,
  а не «Время задачи истекло» с остановкой всей задачи.
- Сообщения о превышении размера называют настоящий лимит вместо постоянного
  «Текстовый файл больше 64 КБ».
- Ошибка обычного чата записывается в чат, откуда ушёл запрос, а не в открытый сейчас.
- История читает из базы только сообщения, которые уйдут модели; старые вложения
  не загружаются в память.
- `tools/package.py` больше не подписывает молча паролем `android`: нужен `LUMA_SIGN_PASS`.

### Важно при обновлении
- APK подписан новым ключом. Версию 0.5.1 и старше, подписанную прежним ключом,
  нужно удалить перед установкой; ключи API, история и загрузки при этом удаляются.
