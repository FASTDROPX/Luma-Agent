# Changelog

## Следующая версия

- Инструменты агента под разрешения: найти контакт, позвонить, отправить и прочитать SMS,
  журнал звонков, местоположение, события календаря, список фото/видео/аудио, статистика
  приложений. Звонок и SMS всегда подтверждаются отдельно, как удаление файла.
- Когда шагу нужен выключенный доступ, агент не падает, а показывает прямо в чате карточку
  «Нужен доступ» в стиле приложения: кнопка «Выдать доступ» открывает системный запрос (или
  экран настроек для особых доступов), после выдачи задача продолжается; «Пропустить» —
  продолжить без него. Запрашивается только то разрешение, что нужно шагу (чтение не просит
  запись).
- «Доступ» → раскрывающийся раздел «Необязательные доступы» (выдано N из M). Внутри три группы:
  «Нужны отдельным действиям Luma» (уведомления, изменение системных настроек, «Не беспокоить»,
  Bluetooth, точные будильники); «Работа в фоне» (отключение энергосбережения, фоновая
  активность, исключение из «Экономии трафика», подсказки для Xiaomi, Huawei/Honor, Samsung,
  OPPO/realme/OnePlus, vivo); «Про запас» — остальные доступы Android: камера, микрофон,
  местоположение (и в фоне), контакты, календарь, телефон, журнал звонков, SMS, фото и видео,
  музыка, физическая активность, датчики, устройства и Wi‑Fi поблизости, все файлы, поверх
  других приложений, доступ к уведомлениям, статистика использования, установка приложений,
  управление медиа, полноэкранные уведомления. Каждая строка показывает, выдано ли, и открывает
  системный запрос или экран Android; обычные разрешения можно запросить разом. Разрешения
  «про запас» инструменты Luma пока не используют — они выдаются заранее.
- В режиме «Агент» интерфейс управления появляется только когда он нужен. Пока агент думает
  или отвечает словами, в чате видна обычная строка «Готовлю ответ…»; карточка агента — с
  первым действием; курсор, свечение, кнопка «Стоп» и плавающая панель — только перед первым
  действием на экране или переходом в другое приложение (нажатия, свайпы, системные действия,
  open_app, open_url…). Вопрос, на который можно ответить в чате, и прямые действия
  (фонарик, громкость, файлы, будильник) обходятся без оверлея.
- Режим «Глубокие размышления» для агента (кнопка «Размышления» рядом с «Агент» и тумблер в
  «Настройки» → «Управление»). Если шаг на экране не удался (ошибка, экран не изменился) или
  агент собирается повторить то же действие на том же экране, он сначала разбирает неудачу:
  почему не вышло, какие есть другие способы, с какого начать. Разбор попадает в рабочие
  заметки и виден в журнале шагов; то же действие на том же экране повторно не выполняется.
  До 6 разборов за задачу, каждый — один дополнительный запрос к модели.
- Ссылки из текста на экране передаются модели отдельно (поле links), и агент открывает их
  через open_url: в Telegram нажатие на сообщение со ссылкой открывало меню сообщения.
- Новое действие long_press — долгое нажатие на элемент, чтобы открыть его меню
  («Копировать», «Поделиться», «Открыть в браузере»).
- Поиск в интернете для любой модели: DeepSeek, локальные и все остальные получают
  инструменты web_search и read_page — модель сама решает, что искать, Luma ищет и открывает
  страницы. Модели без вызова функций ищут через короткий JSON-протокол. До 4 поисков и
  5 страниц на ответ; в чате видно «Ищу: …», «Читаю: …», над ответом — тот же блок
  «найдено / прочитано».
- Поисковики Luma («Настройки» → «Поиск в интернете»): DuckDuckGo без ключа (по умолчанию),
  Tavily и Brave Search по ключу, свой SearXNG по адресу (в том числе через Tailscale).
  Кнопка «Проверить поиск».
- Gemini, Claude, OpenAI и OpenRouter по-прежнему ищут сами; переключатель «Встроенный поиск
  провайдера» позволяет и им искать через Luma.
- Страницы открываются только по HTTPS из публичного интернета: не из домашней сети и не с
  самого телефона; текст страниц передаётся модели как недоверенные данные.

## 0.8.2 — 2026-10-23

> Подписана тем же ключом, что 0.8.0 и 0.8.1: ставится поверх без удаления.

- Поиск в интернете для ответов в чате: кнопка «Поиск» над полем ввода. Модель сама ищет
  через API провайдера — Gemini (Google Search), Claude (web search), OpenAI (Responses API),
  OpenRouter (web plugin); у DeepSeek и локальных серверов такого API нет. Над ответом —
  «Поиск в интернете · найдено N страниц · прочитано M», по нажатию — запросы и список страниц,
  прочитанные отмечены, страница открывается в браузере. Источники попадают и в экспорт чата.
- Черновик сообщения (текст и вложения) сохраняется для каждого чата: при переходе в другое
  меню, в другой чат и после перезапуска.
- Агент в играх (Brawl Stars и др.) больше не встаёт на паузу «повторяются шаги» без причины:
  у таких приложений нет дерева элементов, и защита теперь сравнивает ещё и сами снимки
  экрана (64-битный отпечаток, на телефоне). Пауза — только если картинка не меняется.
- Gemini (и модели Gemini через OpenRouter) получают координаты в шкале 0–1000, в которой они
  обучены указывать точки; раньше нажатия могли уходить мимо — в соседние меню.

## 0.8.1 — 2026-10-23

> Подписана тем же ключом, что 0.8.0: ставится поверх неё без удаления.

- Режим «Чат» / «Агент» сохраняется в каждом чате: не сбрасывается при переходе в другое меню
  и после перезапуска; новый чат начинается в режиме, который был на экране.
- Локальный сервер можно использовать из другого города через Tailscale: HTTP разрешён для
  адресов 100.64.0.0/10 и имён *.ts.net. Инструкция — во вкладке «Модели» и в README.
- Убрана анимация появления текста слева направо в поле ввода чата (и переключатель
  «Плавный ввод»): текст показывается сразу.
- Оверлеи в стиле приложения и компактнее: «Стоп» — небольшая пилюля с градиентным значком
  и строкой текущего шага; плавающая панель — тёмная карточка 248 dp с градиентной главной
  кнопкой, в свёрнутом виде — маленький чип.
- Начало работы агента: обводка плавно растекается по краям экрана от места, где стоял шар,
  и набирает ширину; шар отрывается от своего места и по S-кривой (плавный старт, быстрая
  середина, мягкая посадка) за 1,1 с приезжает в центр экрана.
- Пауза (и ожидание подтверждения): обводка плавно сужается до 5 dp, курсор и частицы
  становятся серыми и полупрозрачными (50 %) и замирают; после продолжения всё так же
  плавно возвращается.
- Завершение: обводка стягивается к ближайшему краю, а курсор плавно уезжает за экран;
  окно оверлея убирается после анимации.
- Когда Luma печатает в текстовое поле, шар за ≈0,4 с перелетает к полю и превращается
  в бело-голубо-фиолетовую каретку с переливающимся градиентом. Текст вводится постепенно,
  каретка следует за буквами по их настоящим координатам на экране (Android 8+; иначе по
  оценке).
- Каретка ведёт себя как «жидкий курсор» из плагина text_animation для exteraGram
  (формулы взяты из его кода и подстроены под быстрый ввод Luma): мягко догоняет новую
  букву, тянется в сторону движения (до 10 dp) и на ходу становится до 30 % толще. Высота
  каретки не меняется.
- Частицы всегда тянутся к курсору: при печати они идут коротким хвостом за кареткой и не
  успевают её догнать. В переполненном однострочном поле их уносит назад вместе с
  прокручиваемым текстом, поэтому они не скапливаются у каретки, которая стоит на месте.
- Исправлено: в конце превращения шар каждый кадр немного откатывался назад — каретка
  могла мерцать.

## 0.8.0 — 2026-10-23

> Новый ключ подписи: поверх 0.7.0 не устанавливается. Удалите старую версию (API-ключи,
> история и загрузки пропадут), затем установите 0.8.0. Следующие версии ставятся поверх 0.8.0.

### Прямые действия вместо поиска в интерфейсе
- Простые операции выполняются одним вызовом инструмента, без чтения экрана: фонарик,
  громкость по каналам (медиа, звонок, уведомления, будильник, разговор, система) и
  отключение звука, режим звонка, яркость и автояркость, автоповорот, «Не беспокоить»,
  медиа (play/pause/next/previous/stop), буфер обмена, состояние телефона (батарея, сеть,
  время, звук, экран, переключатели, память, ближайший будильник).
- Шторка уведомлений, быстрые настройки, недавние приложения, блокировка экрана, меню
  питания, системный снимок экрана, закрытие шторки — через системные действия
  Accessibility, без снимка экрана и без vision.
- `swipe_screen`: стандартные свайпы вверх/вниз/влево/вправо и от края экрана считаются по
  размерам экрана. Текстовая локальная модель может открыть шторку жестом.
- Свайп и нажатие по координатам больше не требуют картинки. Свайп проверяет границы и
  актуальность экрана; нажатие по точке без снимка допускается только внутри элемента
  из дерева, угадывать расположение невидимых кнопок модель не может.
- Приложения по имени (`open_app name=…`), ссылки и deep links (`tel:` открывает набор
  номера, `mailto:`/`sms:` — черновик), страницы настроек и системные панели.
- Будильник и таймер в «Часах» с названием, днями повтора и часовым поясом; событие
  календаря с началом, концом, местом, часовым поясом и повтором (форма для сохранения);
  собственные напоминания Luma с уведомлением, повтором и восстановлением после перезагрузки.
- Wi‑Fi, мобильный интернет, NFC и Bluetooth (Android 13+) Android переключает только в
  своей панели или диалоге: инструмент открывает её и честно возвращает
  `needs_confirmation`. Геолокация, авиарежим и точка доступа — только настройки
  (`needs_user_action`). Ничего не объявляется выполненным, если открыты лишь настройки.

### Реестр инструментов и протокол
- Единый реестр: типизированные аргументы, результат, разрешения, проверки, признак
  побочного эффекта и важности. Из него строятся компактный каталог, JSON-схемы и
  `describe_tool` с подробностями и доступностью на этом устройстве.
- Модель получает возможности устройства: что доступно напрямую, что через подтверждение,
  что только через настройки и что недоступно, а также текущее время и часовой пояс.
- Нативный вызов функций для OpenAI-совместимых API (OpenAI, OpenRouter, DeepSeek,
  Ollama, LM Studio), Claude и Gemini (с сохранением thought signature). Если локальный
  сервер не поддерживает инструменты, задача сама продолжается JSON-командами.
  Настройка «Агент» → «Вызов инструментов»: Авто, Функции, JSON.
- Структурированные статусы результата: done (с verified), needs_confirmation,
  needs_user_action, unsupported, denied, error, unknown.
- Действие с побочным эффектом, результат которого неизвестен, не повторяется без
  подтверждения пользователя — даже в «Полном доступе». Аргументы проверяются до
  выполнения и до запроса подтверждения.

### Рабочая папка
- Модель видит папку как `workspace:/` с названием, расположением («Внутренняя память ›
  Documents»), правами чтения/записи и состоянием доступа; настоящий content:// URI
  остаётся внутри Luma.
- `write_text` создаёт файл сразу, без предварительного `list_files`, и сам создаёт
  недостающие папки; существующий файл без `overwrite` не меняется. Новые инструменты:
  `append_text`, `create_folder`, `file_info`, `search_files`; удаление пустых папок.
- Тип файла определяется по расширению, поэтому `notes.md` не превращается в `notes.md.txt`.
- Если папка не выбрана или доступ потерян, задача сразу заканчивается понятным
  сообщением с путём к системному выбору папки — без поиска через файловый менеджер.

### Размер ответа
- Новое значение по умолчанию «Авто / максимум модели»: Luma не добавляет своего
  ограничения. Поле лимита не отправляется там, где API это допускает (Gemini, OpenAI,
  OpenRouter, DeepSeek, локальные серверы); Claude получает максимум своей модели из
  каталога (поле `max_tokens` Models API) или документированное значение.
- Убран потолок 8192 из каталога, настроек, сохранения и запросов. Старые каталоги с
  урезанным значением считаются «предел неизвестен» до обновления списка.
- Ручной лимит ответа остаётся отдельной настройкой (до максимума модели) и не связан с
  бюджетом токенов задачи и лимитом шагов.

### Доступ
- Карточка «Системные действия»: «Изменение системных настроек», «Не беспокоить»,
  «Устройства поблизости», «Будильники и напоминания» — каждое выдаёт пользователь сам.
- Карточка папки показывает название, расположение и права так же, как их видит модель.

### Проверка
- Новые тесты: шторка и свайп текстовой локальной моделью без картинки, прямые действия
  без чтения экрана, панели и настройки вместо ложного успеха, переход на JSON-команды,
  TXT в workspace через реальный протокол документов, отсутствие папки, «Авто» для всех
  провайдеров, нативные вызовы во всех трёх форматах, подтверждения, «Стоп», повтор
  неизвестного действия, часовые пояса будильника и переход на летнее время.

## 0.7.0 — 2026-10-23

### Сообщения
- Долгое нажатие на сообщение (или «⋯» под ответом) открывает меню: копировать,
  выделить текст, поделиться, удалить, «Спросить ещё раз» для своего вопроса и
  «Перегенерировать» для последнего ответа.
- Если ответ не пришёл, вместо него появляется карточка ошибки с кнопкой
  «Переотправить». Ошибки не попадают в историю, которую видит модель.

### Картинки от модели
- Модели, которые рисуют (Gemini …-image, OpenRouter с выводом картинок, OpenAI
  gpt-image и DALL·E), больше не скрываются из списка и помечены «рисует».
- Картинка показывается в ответе во всю ширину. Нажатие открывает её на весь экран
  с увеличением пальцами, сохранением в «Изображения/Luma» и кнопкой «Поделиться».
- Картинки, которые модель вставила прямо в текст как `data:image`, тоже
  превращаются в обычные изображения.

### Код и Markdown
- Блоки кода: название языка, подсветка по языку (Kotlin, Java, JS/TS, Python, C/C++/C#,
  Go, Rust, Swift, GLSL, JSON, YAML, HTML/XML, CSS, SQL, Bash/PowerShell и другие),
  кнопки «Копировать» и «Скачать» с файлом нужного расширения (`.kt`, `.py`, `.json`…).
  Длинные строки прокручиваются вбок.
- Markdown в цветах приложения: акцентные маркеры списков, ссылки и цитаты, мягкий фон
  у `inline code`, заголовки средней насыщенности, тонкие разделители.

### Чаты
- История: поиск по названиям и тексту, закрепление чатов (сверху, со значком),
  переименование, экспорт в Markdown (.md) и удаление из меню чата.
- Быстрая смена модели: нажмите на название модели в шапке чата.
- «Поделиться → Luma» из других приложений: текст попадает в поле ввода, картинки и
  PDF становятся вложениями.
- Расход токенов: нажмите на метр в шапке — там расход этого чата и за сегодня.

### Агент
- Время каждого шага в ленте («Открыть главный экран · готово · 2,1 с») и раскрывающийся
  журнал шагов со временем и скоростью в карточке агента.
- Лимит токенов на задачу («Управление» → «Лимит токенов на задачу»): при достижении
  агент встаёт на паузу и спрашивает, продолжать ли.
- Когда Luma свёрнута, по окончании задачи приходит уведомление с вибрацией.
- Свёрнутая панель показывает номер шага: «✦ 3».

### Настройки
- «Тон общения»: дружеский («ты») или официальный («вы») — и в текстах приложения,
  и в ответах модели.
- «Размер текста в чате» (85–140 %) и «Вибрация» (короткий отклик при отправке,
  подтверждении, завершении задачи и ошибке).
- «Проверить подключение» на вкладке «Модели»: короткий запрос к выбранной модели,
  её ответ, время и скорость.

### Исправления и мелочи
- Шар Luma в карточке агента теперь внутри карточки, её размер не изменился.
- Приветствие отцентрировано по шару; тексты интерфейса стали короче и проще.
- Ответы в чате больше не проявляются анимацией — появляются сразу.

### Проверка
- 130 юнит-тестов (9 новых: закрепление, переименование, поиск и экспорт чатов,
  ответы с ошибкой, учёт токенов, картинки в трёх форматах API, блоки кода,
  подсветка, тон). Чат, картинки, код, меню, история, тон, размер текста,
  проверка связи, агент, панель «✦ N» и уведомление проверены на эмуляторе Android 15.

## 0.6.0 — 2026-10-22

### Скорость генерации и время работы
- Метр «↑ вход · ↓ выход т/с» для всех провайдеров: в шапке чата под кнопками истории
  и нового чата, в карточке агента и второй строкой на кнопке «Стоп» поверх других
  приложений. Нажатие на метр показывает токены, время до первого токена, время
  рассуждений и общее время. Отключается в «Оформление» → «Скорость генерации».
- Ответы приходят потоком (SSE) у Gemini, Claude, OpenAI-совместимых API и локальных
  серверов — это даёт момент первого токена. Сервер без потока получает обычный запрос.
- Время работы агента (м:сс или ч:мм:сс) в карточке агента, на кнопке «Стоп», в
  раскрытой панели «✦» и в полосе «Luma выполняет задачу»; таймер у «Готовлю ответ…».

### Рассуждения
- Сворачиваемый блок «Рассуждения · N с ›» над ответом, как в DeepSeek: для
  `reasoning_content`/`reasoning` (DeepSeek, OpenRouter, Ollama), мыслей Gemini 2.5+
  и блоков `<think>`. Рассуждения хранятся в истории, но не отправляются модели обратно.

### Чат и интерфейс
- Ответ появляется целиком, без побуквенной анимации; новый ответ плавно проявляется блоком.
- Таблицы: колонки по ширине содержимого вместо равных долей, шапка и сетка,
  широкая таблица прокручивается вбок, а не обрезается.
- Поле ввода: «+», текст и кнопка отправки на одной линии высотой 44 dp;
  кнопка отправки меньше.
- Под ответом — «Копировать» и скорость этого ответа.
- В шапке — короткое имя модели («luma-qwen3 · локально»), без обрыва посреди слова.
- История чатов показывает дату; длинные заголовки, ID моделей, подписи и тексты
  панели заканчиваются многоточием.
- Анимации: плавное появление сообщений и карточки агента, «К последнему»
  появляется и исчезает, раскрытие рассуждений, смена значений метра и этапа агента.

### Оверлей агента
- Кнопка-панель «✦» стоит в одном ряду с «Стоп», той же высоты и в том же стиле.
- Частицы курсора во время перелёта вытягиваются в изогнутый поток вдоль пути, как
  в приветствии, и на месте закручиваются обратно на орбиты.

### Проверка
- 121 юнит-тест (13 новых: поток трёх форматов API, т/с, рассуждения, `<think>`,
  таблицы, миграция истории v3, поток частиц). Чат и агент проверены на эмуляторе
  с фейковым потоковым сервером.

## 0.5.3 — 2026-10-22

### Агент работает с реальными моделями
- Исправлена ошибка «Модель вернула неизвестный тип команды». Модели (Gemini, Qwen)
  часто присылают сразу весь план несколькими командами. Теперь выполняется первая
  команда, а модель получает пометку, что остальные отброшены, и планирует дальше по
  новому экрану. Итог вместе с действиями по-прежнему отклоняется.
- Парсер команд принимает частые отклонения формата: массив, текст или блок
  `<think>` вокруг JSON, пропущенный или синонимичный `type`, поля `name`/`arguments`.
  В тексте ошибки теперь видно начало ответа модели.
- Снимок экрана действителен 10 минут вместо 90 секунд: локальные модели думают над
  шагом дольше минуты. Проверки окна, размера экрана и элемента остаются. Если модель
  не указала `snapshot`, используется последний снимок.
- Нажатие на некликабельную подпись уходит на её ближайший кликабельный контейнер,
  как при нажатии пальцем («Элемент не поддерживает нажатие» больше не мешает).

### Локальный сервер
- Ответа локального сервера Luma ждёт до 5 минут вместо 90 секунд, без лишних повторов.
- Лимит ответа для локальных моделей поднят с 2048 до 8192 токенов: рассуждения
  перед командой больше не обрезают ответ.

### Доступ
- В подсказке «Если Android запрещает включение» появилась кнопка «Открыть настройки
  Luma» — для пункта «Разрешить ограниченные настройки» на Android 13+.

## 0.5.2 — 2026-10-22

### Безопасность агента
- Убран встроенный список «опасных» слов в режиме «Полный доступ»: слова вроде
  «удалить» или «подтвердить» могли означать безобидное действие.
- Новая настройка «Запрещённые слова» («Настройки» → «Параметры модели»). Если слово
  есть в подписи нажимаемого элемента или во вводимом тексте, шаг ждёт подтверждения
  даже в полном доступе. Окно подтверждения называет совпавшее слово. Список общий
  для всех моделей, по умолчанию пуст.
- Нажатие по координатам (`tap_point`) больше не обходит проверку: подпись берётся
  у элемента под точкой и видна в окне подтверждения.

### Конфиденциальность
- Картинки из ответов модели больше не загружаются автоматически. Вместо них
  показывается ссылка «🖼 подпись», которая открывается в браузере только по нажатию.
  Так ответ не может незаметно отправить данные на чужой сервер через адрес картинки.
  Модуль Markwon image удалён из сборки.
- Обычный HTTP разрешён только для локальной сети и теперь проверяется прямо
  в HTTP-клиенте, а не только при сохранении адреса. Локальными также считаются
  169.254.0.0/16 и приватные/link-local IPv6 (fc00::/7, fe80::/10).

### Исправления
- Зависший жест (Android не подтвердил его за 5 с) — теперь ошибка одного шага,
  а не «Время задачи истекло» с остановкой всей задачи.
- Сообщения о превышении размера называют настоящий лимит вместо постоянного
  «Текстовый файл больше 64 КБ».
- Ошибка обычного чата записывается в чат, откуда ушёл запрос, а не в открытый сейчас.
- История читает из базы только сообщения, которые уйдут модели; старые вложения
  не загружаются в память.
- `tools/package.py` больше не подписывает молча паролем `android`: нужен `LUMA_SIGN_PASS`.

### Важно при обновлении
- APK подписан новым ключом. Версию 0.5.1 и старше, подписанную прежним ключом,
  нужно удалить перед установкой; ключи API, история и загрузки при этом удаляются.
